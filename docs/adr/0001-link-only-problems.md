# ADR-0001: 문제는 링크로만 저장하고 지문은 가져오지 않는다

- 상태: 채택
- 날짜: 2026-10-29

## 배경

문제를 한곳에 모으고 싶지만, 문제와 지문은 각 사이트의 것이다. LeetCode 약관은 문제와 풀이가 자기 소유라고 밝히고 스크래핑을 막는다. 저작권 신고(DMCA)로 저장소를 내린 기록도 있다. 프로그래머스, 백준 약관에서 같은 조항은 직접 찾지 못했다.

## 결정

- 저장하는 것: 링크, 사이트, 번호, 제목, 유형 태그, 내 말로 쓴 한 줄 요약, 내 코드, 메모, 복습 기록
- 저장하지 않는 것: 지문, 예제, 그림, 공식 해설, 유료 문제 내용
- 좋은 문제 모음은 NeetCode 로드맵처럼 링크 목록으로 둔다
- 우리가 직접 만드는 문제는 프론트엔드 구현 문제부터(debounce, Promise.all 구현 등). 지문과 테스트를 우리가 쓰고 브라우저에서 채점한다

## 이유

약관을 찾지 못한 사이트도 같은 원칙으로 보면 어느 사이트든 걱정 없이 쓸 수 있다. 복습 카드 앞면이 지문이 아니라 내 요약이어서, 오히려 "내 말로 설명할 수 있나"를 확인하게 된다.

## 고려한 대안

- 지문을 긁어 저장: 약관 위반 위험, 저장소를 공개하면 신고 대상
- 지문 일부만 인용: 어디까지 괜찮은지 판단할 근거가 없다

## 결과

- 복습할 때 지문이 필요하면 원래 사이트를 연다
- 요약을 안 쓰면 카드 앞면이 제목뿐이라 떠올리기가 약해진다. 요약 칸을 맨 위에 둔다(ADR-0005)
