# ADR-0002: 문제 사이트 옆에 크롬 확장 사이드 패널을 붙이고, 제출은 내가 한다

- 상태: 채택
- 날짜: 2026-10-29

## 배경

에디터와 메모를 문제 옆에 두고 싶었다. 프로그래머스와 LeetCode 는 `X-Frame-Options: SAMEORIGIN` 이라 우리 화면 안에 띄울 수 없다(2026-10-29 curl 확인). 백준 문제 주소는 그날 404였다.

## 결정

- 문제를 우리 화면에 넣는 대신 우리 도구를 문제 옆으로 가져간다. 왼쪽은 원래 사이트, 오른쪽 크롬 사이드 패널에 에디터, 메모, 타이머
- 패널이 주소로 사이트와 문제 번호를 알아보고 전 기록을 불러온다
- "코드 복사" 버튼만 두고, 제출은 내가 사이트에서 직접 누른다
- 채점 결과 "맞았습니다"를 감지해 기록을 자동으로 남긴다(백준허브 방식). 감지가 실패해도 패널의 직접 기록 버튼으로 남길 수 있다
- 확장 없이 쓸 때를 위해 웹에 "나란히 열기"(문제를 왼쪽 절반 창으로 여는 버튼)를 둔다
- 첫 버전은 프로그래머스와 LeetCode. 백준은 운영 상태를 확인한 뒤

## 이유

문제를 푸는 자리가 기록하는 자리가 되면 "나중에 정리해야지"가 사라진다. 대신 제출하면 사이트 약관과 부딪히고, 제출 버튼을 누르는 일은 오래 걸리지 않는다.

## 고려한 대안

- 우리 화면에 iframe 으로 넣기: 두 사이트가 막는다
- 웹 앱만 두고 창 두 개를 손으로 배치: 매번 번거로워 기록을 미루게 된다. 확장이 없을 때의 길로만 남긴다
- 자동 제출: 약관 위험

## 결과

- 사이트 화면이 바뀌면 번호 인식과 결과 감지가 깨진다. 백준허브도 2026-03 에 프로그래머스 업로드가 고장 났다는 리뷰가 있었다. 감지 규칙을 사이트별 파일 하나에 모아 고치기 쉽게 한다
- 에디터와 메모는 웹과 확장이 같이 쓰는 부품이어야 한다(ADR-0003)
