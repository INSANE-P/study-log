# ADR-0003: 에디터는 CodeMirror 6, 실행은 서버 없이 브라우저에서

- 상태: 채택
- 날짜: 2026-10-29

## 배경

좁은 사이드 패널과 웹 화면 양쪽에서 같은 에디터를 써야 한다. 주 언어는 파이썬, 보조는 자바스크립트다(2026-10-30 사용자). 코드를 돌릴 서버는 두고 싶지 않다.

## 결정

- CodeMirror 6 에 VS Code 단축키를 붙인다
- 언어는 파이썬, 자바스크립트 탭. 같은 문제의 두 풀이를 따로 저장한다. 처음 여는 탭은 파이썬
- 실행은 브라우저에서. 자바스크립트는 Web Worker, 파이썬은 Pyodide. 무한 반복에 대비해 시간 제한을 두고 넘으면 Worker 를 끊는다
- 테스트 입력은 내가 만든 것만. 최종 채점은 원래 사이트 제출(ADR-0002)
- 에디터, 실행기, 메모는 웹과 확장이 같이 쓰는 부품으로 만든다

## 이유

CodeMirror 6 는 Monaco 보다 가벼워 좁은 패널에서도 빨리 뜬다. 브라우저 실행은 서버 비용과 보안 걱정이 없다.

## 고려한 대안

- Monaco: VS Code 와 같지만 무겁고 패널 폭에 맞추기 어렵다
- 서버에서 실행(Judge0 등): 서버가 생기고 혼자 쓰기엔 과하다

## 결과

- Pyodide 는 처음 받을 때 크다. 한 번 받으면 캐시되도록 두고, 첫 실행 때 내려받는 중임을 보여 준다
- 파이썬 표준 입력(`input()`) 흉내를 실행기가 맡아야 한다
