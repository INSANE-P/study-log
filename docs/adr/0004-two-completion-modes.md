# ADR-0004: 자동완성은 연습 모드와 시험 모드 두 가지, AI 자동완성은 없다

- 상태: 채택
- 날짜: 2026-10-29

## 배경

코테 시험장 에디터는 자동완성이 거의 없다. 평소에 다 켜고 연습하면 시험에서 손이 멈춘다. 반대로 처음 배울 때 다 끄면 오타에 시간을 쓴다.

## 결정

- 연습 모드: 괄호 닫기, 문법 색, 단어 자동완성 켬
- 시험 모드: 단어 자동완성 끔, 타이머 켬. 복습 때 다시 풀기는 이 모드가 기본
- AI 코드 자동완성은 넣지 않는다

## 이유

연습과 시험의 조건을 나눠야 복습이 실제 시험을 닮는다. AI 자동완성은 떠올리기 연습 자체를 대신해 버린다.

## 고려한 대안

- 모드 하나에 항목별 켜고 끄기: 매번 고르는 일이 생긴다

## 결과

- 시험 모드 기본값이 불편하면 문제별로 연습 모드로 돌릴 수 있게 한다
