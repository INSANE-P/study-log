# ADR-0005: 메모는 네 칸이고, 꼭 넣을 것은 결과 하나다

- 상태: 채택
- 날짜: 2026-10-29 (결과만 필수인 것은 2026-10-30)

## 배경

자동 업로드 도구(백준허브, 코깃코깃)는 코드는 쌓아 주지만 왜 막혔는지는 남지 않는다. 반대로 노션 기록장은 칸이 많아 손이 많이 가서 안 쓰게 된다(`docs/research/2026-10-29-similar-services.md`). 바쁜 날도 기록할 수 있어야 한다(`docs/brief.md`).

## 결정

메모는 네 칸이고 모두 비워도 저장된다. 꼭 넣을 것은 결과(혼자 풂 / 힌트 봄 / 못 풂) 하나다.

1. 내 말로 요약: 복습 카드 앞면이 된다
2. 접근: 코드 쓰기 전 두 줄
3. 막힌 곳: 쓰는 순간 타이머 시간이 찍힌다
4. 언어 메모: 언어 메모장에도 모인다(예: 파이썬 `heapq` 는 최소 힙)

## 이유

막힌 곳과 그 시간이 남아야 "무엇을 다시 볼지"를 고를 수 있다. 칸을 강제하면 기록을 미루게 되므로 결과만 받고, 요약이 비어 있으면 복습 카드를 만들 때 한 번 더 묻는다.

## 고려한 대안

- 자유 메모 한 칸: 요약과 막힌 곳이 섞여 카드로 쓰기 어렵다
- 네 칸 모두 필수: 바쁜 날 기록을 포기하게 된다

## 결과

- 요약이 빈 문제는 카드 앞면이 제목만이다. 오늘 화면에서 "요약이 빈 문제"를 따로 보여 줄지는 써 보고 정한다
