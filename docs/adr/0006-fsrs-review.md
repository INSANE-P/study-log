# ADR-0006: 복습 간격은 ts-fsrs 로 정한다

- 상태: 채택
- 날짜: 2026-10-29

## 배경

"풀어도 잊어서"가 안 이어진 이유 중 하나였다(`docs/brief.md`). 언제 다시 볼지를 내가 정하면 결국 안 본다. 내 다른 프로젝트인 학습 플래너 하루치는 큰 진도 단위라 FSRS 를 쓰지 않았지만, 여기는 문제와 CS 카드처럼 작은 단위라 맞다.

## 결정

- ts-fsrs(Anki 의 FSRS 공개 구현)로 카드마다 다음 복습 날을 정한다
- 결과 세 가지를 FSRS 등급에 잇는다: 혼자 풂 → Good, 힌트 봄 → Hard, 못 풂 → Again. 아주 쉽게 풀었으면 Easy 를 고를 수 있다
- 힌트를 몇 단계까지 봤는지(ADR-0007 의 3단계 힌트)도 기록해, 같은 Hard 라도 나중에 나눠 볼 수 있게 둔다
- 복습은 두 가지: 카드로 떠올리기(요약을 보고 접근과 막힌 곳을 떠올림)와 다시 풀기(시험 모드, ADR-0004). 둘 다 같은 카드의 기록이다
- FSRS 기본 매개변수로 시작하고, 기록이 쌓이면 최적화는 나중에

## 이유

간격 반복은 연구가 많고, FSRS 는 Anki 에 기본으로 들어갈 만큼 검증됐다. 공개 구현이 있어 직접 짤 필요가 없다.

## 고려한 대안

- 고정 간격(1, 3, 7, 14일): 쉬운 문제와 어려운 문제가 같은 간격을 받는다
- SM-2: FSRS 보다 오래됐고 예측이 덜 맞는다

## 결과

- 결과 세 가지와 FSRS 네 등급이 1:1 이 아니라, Easy 를 따로 누를 자리가 필요하다. 화면에서 어떻게 보일지는 화면 단계에서 정한다
- 브리프의 Y2(혼자 풂 비율)는 이 복습 기록으로 잰다
