# ADR-0008: CS 는 "주소창에 URL 을 치면" 한 줄기로, 15분 단원과 복습 카드로 배운다

- 상태: 채택
- 날짜: 2026-10-29

## 배경

수시 전형은 과제와 면접이 많아 프론트엔드 CS 질문이 먼저 온다(`docs/brief.md`). 흩어진 면접 질문 목록을 외우면 꼬리 질문에서 막힌다.

## 결정

- 큰 줄기 "주소창에 URL 을 치면": 1주 네트워크, 2주 HTTP 와 캐시, 3주 브라우저, 4주 보안, 5주 운영체제, 6주 DB. 자료구조는 코테와 함께
- 한 단원 15분: 질문 → 3분 설명(비유 하나, 단계별 그림) → 직접 확인(개발자 도구, `curl -I`) → 내 프로젝트와 잇기 → 내 말로 설명(AI 가 빈 곳을 짚음) → 복습 카드 2~3장
- 카드 네 종류: 설명하기, 순서 맞추기, 틀린 곳 찾기, 상황 문제
- 내용은 책과 블로그를 옮기지 않고 새로 쓴다. 단원마다 MDN, web.dev 같은 공식 문서 근거를 달고, 대조 전엔 "확인 전"으로 표시한다
- 질문 재료: 프론트엔드 공고에 적힌 기술 질문과, 지원하며 따로 모아 둔 예상 면접 질문(개인 저장소에 있고 여기로 옮기지 않는다)
- 단원은 저장소의 마크다운 파일. 첫 주는 네트워크 다섯 단원만

## 이유

한 줄기로 이으면 각 질문이 앞 단계와 이어져 꼬리 질문을 따라갈 수 있다. 직접 확인하는 단계가 있어야 외운 말이 아니라 본 것으로 답한다.

## 고려한 대안

- 면접 질문 목록 그대로: 서로 이어지지 않아 금방 잊는다
- 외부 강의: 유료이고 속도가 정해져 있다

## 결과

- 단원 내용은 직접 써야 해서 시간이 든다. 한 주에 다섯 단원씩만
