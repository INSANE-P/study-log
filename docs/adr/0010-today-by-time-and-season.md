# ADR-0010: 오늘 화면은 쓸 수 있는 시간에 맞춰 세 크기로, 시기마다 CS 와 코테 비중을 옮긴다

- 상태: 채택
- 날짜: 2026-10-30

## 배경

처음엔 오늘 화면을 "새 문제 1, 복습 1, CS 질문 3"으로 고정했다. 2026-10-30 에 물어보니 하루 시간은 날마다 다르고, 바쁜 날은 복습 카드 3장, 5분만 해도 한 날로 치고 싶다고 했다. 수시 지원과 3월 공채를 같이 간다.

## 결정

- 오늘 화면은 할 것을 세 크기로 내놓는다
  - 5분: 복습 카드 3장
  - 30분: 위 + 복습 문제 하나 또는 새 문제 하나 + CS 카드 3장
  - 1시간 이상: 위 + 새 문제 하나 + CS 단원 하나
- 작은 크기를 끝내면 그날은 "한 날"이다. 더 하고 싶으면 다음 크기의 남은 것만 이어서 보여 준다
- 시기마다 무게를 옮긴다. 2026-11~12 는 CS 쪽이 더 크고(새 CS 단원이 먼저 나옴), 2027-01 부터는 코테 쪽이 더 크다(새 문제가 먼저 나옴)
- 시기 경계와 각 크기의 구성은 설정 파일 하나에 두고, 공채 일정이 나오면 고친다

## 이유

고정된 하루치는 바쁜 날 "어차피 다 못 하니 내일"이 된다. 가장 작은 단위를 성공으로 쳐 주면 끊기지 않는다. 내 학습 플래너 하루치가 탓하지 않는 문구와 월요일 새 출발을 넣은 것과 같은 근거다(Silverman and Barasch 2023, Dai 외 2014).

## 고려한 대안

- 고정 구성: 위의 이유로 뺐다
- 시간을 분 단위로 입력받아 계산: 고르는 일이 무거워진다. 세 크기면 충분하다

## 결과

- 복습이 밀리면 카드가 많이 쌓인다. 5분 크기는 밀린 카드 중 급한 3장만 내놓고 나머지는 다음 날로 미룬다
