# ADR-0012: 브랜드의 얼굴은 채점 표시(○ △ 접힌 귀퉁이)이고, 노트 칸과 새 장과 칠한 칸이 받친다

- 상태: 대체(ADR-0015)
- 날짜: 2026-10-30

## 배경

브랜드와 디자인을 먼저 하기로 했다(`docs/pipeline.md`). 공부 도구의 실제 사물에서 컨셉 후보 일곱을 만들고(`docs/research/2026-10-30-concept-candidates.md`), 서로 못 보는 심사위원 다섯(바쁜 취준생, 학습과학 연구자, 프론트엔드 면접관, 브랜드 디자이너, 모션 디자이너)이 채점했다(`docs/research/2026-10-30-concept-scores.md`). A(빨간 펜) 98점, C(오답노트) 94점, E(책갈피와 새 장) 87점. 1등 표는 A 넷, C 하나. A 의 약점은 넷이 짚은 이어짐(시험지의 압박, 빨강은 틀림)이었다.

## 결정

네 후보의 강한 곳만 모은다(2026-10-30 사용자 선택).

- **얼굴은 채점 표시(A).** 결과 셋을 서로 다른 필기 동작으로 보인다. 혼자 풂은 한 획 동그라미(○), 힌트 보고 풂은 세모(△), 못 풂은 빗금이 아니라 귀퉁이를 접는다(다시 볼 표시). 로고, 결과 버튼, 캐릭터가 같은 선을 나눠 쓴다
- **사이드 패널의 메모는 노트 칸(C).** 요약, 접근, 막힌 곳, 언어 메모 네 칸을 노트 한 장의 칸으로. 복습 때는 가려 둔 칸을 떼어 드러낸다(먼저 떠올리고 답을 확인)
- **다시 여는 날은 새 장(E).** 월요일이나 오래 쉰 뒤 처음 열면 새 장이 먼저 펴진다. "밀린 복습 N개"를 첫 화면에 쌓지 않는다
- **기록은 칠한 칸(D).** 공부한 시간만큼 칸이 칠해지고 그 위에 ○ △ 가 찍힌다. 빈 칸은 그냥 종이(ADR-0011)
- **빨강은 채점 표시에만.** 인쇄 잉크 빨강을 ○ △ 접힌 귀퉁이에만 쓴다. 본문은 남색 볼펜, 오류와 경고는 다른 색, 에디터 문법 색에서는 빨강을 비운다(2026-10-30 사용자 선택)
- 이름에 "빨간펜"은 쓰지 않는다. 교원그룹의 학습지 브랜드다

## 이유

- 결과를 고르는 순간이 하루에 가장 많이 일어나는 동작이다. 그 동작에 뜻 있는 움직임(한 획으로 그려지는 동그라미)이 붙으면 장식 없이도 기억에 남는다(면접관, 모션)
- 움직임을 줄이는 설정에서도 완성된 표시만으로 뜻이 남는다(모션)
- 학습 연구와 맞는다: 가린 칸 떼기는 떠올리기 연습(Roediger and Karpicke 2006), 새 장은 새 출발 효과(Dai 외 2014), 칠한 칸만 보이는 기록은 끊긴 기록을 보여 주지 않기(Silverman and Barasch 2023)

## 고려한 대안

- A 만(시험지와 채점 표시): 가장 단순하지만 시험지의 압박이 남는다
- C 오답노트 중심(학습과학 1등): 메모 구조는 가장 좋지만 "오답"이 실패를 앞세우고 노란 포스트잇은 흔하다
- G 도토리 다람쥐: 비유는 간격 반복 그 자체지만 공부 도구라는 게 바로 안 보인다
- 빨강 대신 다른 펜 색: 틀림 연상은 사라지지만 채점 느낌이 약해진다

## 결과

- 학습과학 심사위원의 경고를 지킨다. 칠한 칸이나 ○ 개수를 보상처럼 키우면 눈에 보이는 새 연속 기록이 된다. ○ 를 점수처럼 보이게 하면 힌트 본 것을 숨기고 싶어진다. 그래서 ○ 개수나 비율을 큰 숫자로 앞세우지 않고, △ 와 접힌 귀퉁이도 ○ 와 같은 무게로 그린다
- 바탕은 크림이 아니라 푸른 기가 살짝 도는 복사지 흰색, 선은 한 가지 굵기의 펜선에서 시작한다(브랜드 심사위원 제안). 정확한 값은 `docs/brand.md` 에서 정한다
