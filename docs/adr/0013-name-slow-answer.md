# ADR-0013: 이름은 "느린정답"

- 상태: 채택
- 날짜: 2026-10-30

## 배경

`study-log` 는 작업 이름이다. 컨셉(ADR-0012)이 정해져 이름을 지었다. 첫 판 후보(한칸, 한획, 귀퉁이, 동그라미, 새 장, 채점장, 갈피)는 사용자가 "좀 특색있지만 기발한 그리고 직관적인, 안겹칠만한" 이름을 원해 다시 뽑았다. 둘째 판은 Claude, Codex, 제미나이가 같은 조건으로 따로 냈다.

## 결정

이름은 **느린정답**(2026-10-30 사용자 선택, 제미나이 후보).

## 이유

- 한국 학생이면 누구나 아는 문제집 맨 앞장의 "빠른 정답"을 뒤집었다. 듣자마자 공부와 채점이 떠오르고(직관), 한 번 더 생각하면 뒤집기가 보인다(재치)
- 도구의 생각과 맞는다. 정답에 빨리 가는 게 아니라 내 속도로, 잊을 때쯤 다시 와서 내가 떠올린 정답이다(간격 반복, 떠올리기). 힌트를 봤든 못 풀었든 늦게 오는 정답도 정답이다(탓하지 않음)
- 2026-10-30 검색: 웹 검색, 구글 플레이 검색, 한국 앱스토어 검색 모두 같은 이름의 앱이 없었다

## 고려한 대안

- 자채점("자, 채점" + 스스로 채점): 재치는 있지만 "자가채점"의 줄임말로만 들릴 수 있다
- 다시봄(다시 본다 + 다시 봄): 새 장과는 맞지만 채점 표시 컨셉과 멀다
- 채점은내가: 역할 반전이 선명하지만 다섯 글자라 아이콘과 패널 머리에 길다
- 빨간펜: 교원그룹 학습지 상표

## 결과

- 코드가 느리다는 뜻(시간 초과)으로 읽힐 여지가 있다. 첫 화면과 소개 한 줄에서 "빠른 정답"을 뒤집은 이름이라는 게 보이게 한다
- 확인 못 한 것: 특허청 상표 출원 여부. 혼자 쓰는 도구라 지금은 막지 않지만, 남에게 열기 전에 확인한다
- 영문 표기, 로고, 저장소와 주소 이름은 `docs/brand.md` 에서 정한다
