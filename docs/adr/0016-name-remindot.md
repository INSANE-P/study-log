# ADR-0016: 이름은 Remindot(리마인닷)

- 상태: 채택
- 날짜: 2026-10-30
- 대체: ADR-0013(느린정답)

## 배경

미래지향 방향으로 다시 정하며(ADR-0015) 이름도 바꿨다. 사용자 조건: "발음도 쉽고 뭔가 그 뜻도 좀 직관적으로", "다른 서비스랑 그리고 크롬 확장 프로그램으로 배포했을때도 겹치지 않도록".

## 결정

이름은 **Remindot**, 한글 표기 **리마인닷**(2026-10-30 사용자 선택, 제미나이 후보).

## 이유

- remind(다시 떠올리게 하다) + dot(점). 잊을 때쯤 점 신호로 다시 떠올리게 한다는 일을 그대로 말한다
- 대표 장면(점이 흩어졌다 모여 또렷해짐, 캐릭터가 빛 점으로 된 정령)과 이어진다
- 겹침 검사(2026-10-30): 한국 앱스토어, 미국 앱스토어, 구글 플레이, 크롬 웹 스토어, 웹 검색(DuckDuckGo) 다섯 곳에서 "Remindot", "리마인닷" 모두 같은 이름이 없었다. 검사기는 Anki, Quizlet 처럼 있는 이름은 모든 곳에서 잡았다

## 고려한 대안

- 1차 영어 합성어(Remping, Keepalive, RePing 등): 설명이 필요해 "직관적"이 약했다
- 또렷: 뜻은 가장 잘 맞지만 구글 플레이에 "또렷 돋보기", "또렷 브라우저"가 있다
- Reglow, Lumem: 사진 보정 앱, 크롬 확장 "Lumem Clipper"와 겹친다
- Vividot(비비닷), 다시빛, 기억점: 겹침 없음, 최종 후보에 올렸으나 사용자가 Remindot 을 골랐다

## 결과

- 할 일 알림 앱처럼 읽힐 수 있다. 첫 화면과 소개 한 줄에서 "기억 신호"가 보이게 한다
- 확인 못 한 것: 특허청 상표 출원 여부, 도메인. 크롬 웹 스토어에 올리기 전에 확인한다
