# 자산 기록

생성 그림의 프롬프트와 모델, 다시 만드는 법. 몇 달 뒤 같은 캐릭터를 다시 뽑을 수 있게 남긴다.

## 달팽이 (2026-10-30)

| 단계 | 도구와 모델 | 무엇을 했나 |
| --- | --- | --- |
| 1판 시안 | 제미나이(Antigravity CLI `agy`), gemini-4-argon-high 가 Nano Banana 2 이미지 도구를 부름 | 껍데기를 공부 사물로 한 네 안. 빨간 펜 한 획 나선을 고름 |
| 2판 시안 | 같음, 1판의 한 칸을 참조로 | 큰 껍데기와 감은 눈, 붓펜 선, 졸린 눈, 한 획 자국. 셋을 합치기로 |
| 확정 밑그림 | 같음, 2판의 세 칸을 참조로, 초록(#00FF00) 바탕 | 첫 결과가 껍데기를 빨강으로 채워 "속은 흰색, 선만 빨강"으로 한 번 고쳐 받음. `brand/source/snail-master.jpg` |
| 벡터 | Claude, `scripts/brand/trace_snail.py` → `scripts/brand/assemble_snail.py` | 밑그림에서 선의 가운데(가늘게 하기)와 굵기(거리 변환)를 재서 SVG 로 다시 그림. 더듬이는 위치만 맞춰 직접 그림 |

다시 만들기(저장소 맨 위에서):

```bash
python -I scripts/brand/trace_snail.py
python -I scripts/brand/assemble_snail.py public/brand
```

확정 밑그림 프롬프트의 핵심:

- 2판 1번 칸의 비율과 얼굴, 2번 칸의 붓펜 선(껍데기에만), 4번 칸의 한 획 자국을 합친다
- 몸은 낮고 통통하게, 소품 없이, 점액과 광택 없이, 유명 만화 달팽이와 닮지 않게
- 색은 흰색, 빨강 `#D3263A`, 잉크 `#22262E` 만. 그라데이션, 질감, 그림자 없음

그림 단계마다의 전체 프롬프트와 생성 기록은 개인 작업 기록 저장소에 있다.

## 알게 된 것

- 자동 벡터(vtracer)는 가는 선이 많은 그림에서 판정을 못 넘는다(색 차이 상위 1% 74, 기준 45)
- 확정 밑그림의 껍데기는 한 획이 아니라 두 획(안쪽 나선, 바깥 바퀴)으로 그려져 있다. 움직임용 가운데 선은 둘을 이어 한 줄로 만든다
- 생성 그림은 정사각형이 아닐 수 있다. 화면 시안 그림은 1376x768 로 나왔다
