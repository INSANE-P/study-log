# 브랜드

느린정답의 이름, 캐릭터, 표시, 색, 글자를 쓰는 규칙이다. 왜 그렇게 정했는지는 ADR-0012(컨셉), ADR-0013(이름), ADR-0014(캐릭터). 만든 과정과 프롬프트는 `docs/assets.md`.

## 이름

- **느린정답**. 문제집 맨 앞장의 "빠른 정답"을 뒤집었다. 띄어 쓰지 않는다
- 소개 한 줄은 "빠른 정답"을 뒤집은 이름이라는 게 보이게 쓴다(코드가 느리다는 뜻으로 읽히지 않게, ADR-0013)

## 캐릭터: 달팽이

| 파일 | 쓰는 곳 |
| --- | --- |
| `public/brand/snail.svg` | 큰 그림, 빈 화면, 새 장, 굿즈, 소개 |
| `public/brand/shell-mark.svg` | 앱 아이콘, 파비콘, 패널 머리, 로딩. 몸 없이 껍데기 나선만 |

### 지키는 것

- 껍데기는 흰 종이 위의 빨간 붓펜 나선이다. 바깥은 굵고 안으로 감길수록 가늘어지고, 가운데 끝은 펜을 뗀 자국으로 끝난다
- 껍데기가 몸보다 크다(약 1.5배). 실루엣만으로 알아본다
- 몸은 낮고 통통하고 하얗고 말라 있다. 점액, 광택, 혀는 없다
- 눈은 감은 반달, 입은 작은 미소. 짧은 더듬이 끝은 작은 흰 동그라미
- 바닥 자국은 빨간 한 줄이다. 공부한 길이다. 끊긴 곳을 그리지 않는다

### 하지 않는 것

- 몸에 소품을 더하지 않는다(안경, 연필, 지우개). 지우개는 "지우지 않고 접어 남긴다"와 부딪히고 가루가 배설물로 읽힌다
- 화난 얼굴, 실망한 얼굴, 우는 얼굴을 만들지 않는다. 다그치지 않는 성격이다(ADR-0011)
- 껍데기를 빨강으로 채우지 않는다. 빨강은 선에만 쓴다

### 크기

- 가로 96px 이상: 전체를 쓴다
- 그보다 작으면: 껍데기 표시만 쓴다. 24px 에서는 몸과 얼굴이 뭉개진다
- 어두운 바탕에서는 몸 윤곽이 바탕에 묻히므로, 흰 몸이 실루엣을 맡는다

### 움직임

- 껍데기 나선은 가운데 선(`#shell-center`)을 따라 한 획으로 드러난다. 첫 화면에서 한 번, 혼자 풀었을 때 ○ 와 같은 움직임
- 자세와 표정 시트는 화면 시안을 만들며 필요한 것만 더한다

## 채점 표시

| 결과 | 표시 |
| --- | --- |
| 혼자 풂 | 빨간 한 획 동그라미(○) |
| 힌트 보고 풂 | 빨간 세모(△) |
| 못 풂 | 종이 귀퉁이 접기(다시 볼 표시) |

- 셋은 같은 무게로 그린다. ○ 만 크게 키우지 않는다(ADR-0012)
- 체크(✓)는 쓰지 않는다. 한국에서 틀림으로 읽힐 수 있다

## 색

| 이름 | 값 | 쓰는 곳 |
| --- | --- | --- |
| 잉크 | `#22262E` | 선, 글자 |
| 채점 빨강 | `#D3263A` | 채점 표시, 달팽이 껍데기와 자국에만 |
| 종이 | `#FFFFFF`, `#F6F8F7` | 바탕 |
| 하늘 | `#9CC3E0` | 형광펜 칠, 선택 영역 |

- 빨강은 채점 표시에만. 오류와 경고는 다른 색으로 가른다
- 나머지 색과 어두운 바탕은 화면 시안에서 정해 이 표를 채운다(`docs/pipeline.md` 3-5)

## 글자

화면 시안에서 정한다. 코드는 JetBrains Mono 쪽으로 기운다(0 과 O, 1 과 l 이 갈린다).
