# 데이터 (초안)

무엇을 저장하는지 적는다. 지문은 저장하지 않는다(ADR-0001). 모든 테이블은 RLS 로 내 계정만 읽고 쓴다(ADR-0009). 실제 스키마는 `supabase/migrations/` 가 정본이고, 이 문서는 뜻을 적는다.

| 테이블 | 무엇 | 주요 칸 |
| --- | --- | --- |
| problems | 문제 하나 | 사이트, 번호, 제목, 링크, 유형 태그, 내 요약 |
| attempts | 한 번 푼 기록 | 문제, 언어, 결과(혼자 풂 / 힌트 봄 / 못 풂), 접근, 막힌 곳(시간 찍힌 줄들), 코드, 걸린 시간, 힌트 단계, 푼 날 |
| cards | 복습 카드 | 출처(문제 또는 CS 단원), 종류(문제, 설명하기, 순서 맞추기, 틀린 곳 찾기, 상황 문제), 앞면, 뒷면, FSRS 상태 |
| reviews | 카드 복습 한 번 | 카드, 방식(떠올리기, 다시 풀기), 결과, FSRS 등급, 복습한 때 |
| cs_progress | CS 단원 진도 | 단원 파일 이름, 끝낸 날, 내 말로 쓴 설명 |
| lang_notes | 언어 메모 | 언어, 내용, 나온 문제 |
| weekly_posts | 주간 글 재료 | 주(월요일 날짜), 모인 기록, 노션 초안 주소 |

- CS 단원 내용 자체는 저장소의 마크다운 파일이다(ADR-0008). DB 에는 진도와 내 설명만
- "한 날"(`docs/brief.md`)은 attempts, reviews, cs_progress 의 날짜로 계산한다. 따로 저장하지 않는다
- 날짜는 한국 시간 기준으로 하루를 끊는다
