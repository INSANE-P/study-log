# 비슷한 서비스와 약관 조사 (2026-10-29)

study-log 를 시작하기 전 대화에서 조사한 내용이다. 확인한 것과 못 한 것을 나눠 적는다.

## 비슷한 서비스

| 종류 | 예시 | 좋은 점 | 빈 곳 |
| --- | --- | --- | --- |
| 풀이 사이트 | 프로그래머스, 백준, LeetCode | 문제와 채점 | 계획과 복습은 내가 챙긴다 |
| 커리큘럼 | 코드트리, 인프런 강의 | 순서가 있다 | 유료, 정해진 속도 |
| 자동 업로드 | 백준허브(1.4.7, 2026-03-31), 코깃코깃 | 코드가 쌓인다 | 막힌 이유는 안 남는다. 3월에 프로그래머스 업로드 고장 리뷰 |
| 복습 알림 | LeetSRS, AlgoRecall, NeetCode Pro(연 $119) | 다시 보여 준다 | LeetCode 전용, 영어 |
| FE 면접 | GreatFrontEnd(평생 $180~360), BFE.dev | 문제와 풀이가 많다 | 영어, 국내 면접과 결이 다르다 |
| 노션 템플릿 | 각자 만든 기록장 | 자유롭다 | 손이 많이 가서 안 쓰게 된다 |

빈칸: 사이트와 상관없이 한곳에 모으고, 막힌 이유를 남기고, 그걸로 복습을 고르고, 기록이 블로그 초안이 되는 것.

## 확인한 것

- LeetCode 약관: 문제와 풀이는 LeetCode 소유, 스크래핑 금지(ADR-0001)
- 프로그래머스, LeetCode 는 `X-Frame-Options: SAMEORIGIN`(2026-10-29 curl, ADR-0002)
- 백준: 2026-04 종료 공지, 6월 데이원컴퍼니 인수 보도
- 2026-10 에 지원한 프론트엔드 수시 공고 네 곳의 전형(2026-10-30 확인): 서류 다음은 미니 프로젝트나 과제, 적성 검사, 면접. 넷 다 코딩테스트 단계가 공고에 없다

## 확인 못 한 것

- 프로그래머스, 백준 약관의 스크래핑과 저작권 조항
- 백준의 지금 운영 방식과 solved.ac 상태. 2026-10-29 문제 주소가 404였다
- 코드트리 요금, BFE.dev 요금
- 삼성 SW 역량테스트 지원 언어(파이썬 됨, JS 안 됨으로 알고 있으나 공고 확인 필요)
